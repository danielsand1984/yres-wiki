# How it works

> One platform, from data source to dashboard.

## 1. Connect your sources without code
Native connectors with Exact Online, AFAS, SAP, Salesforce, databases, REST APIs and more. See the [integration catalog](../integraties/catalogus.md).

## 2. Design pipelines visually, Yres translates them into ADF
Yres automates data flows and translates processes directly into Azure Data Factory. Existing manual ADF pipelines can keep running alongside Yres in the same Azure environment.

## 3. Automatic health checks and cost monitoring
Get insight into pipelines, logging and costs, so dashboards stay reliable and management becomes predictable.
