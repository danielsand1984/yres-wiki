# REST API

**Category:** REST

Generic REST connection for any JSON API. OpenAPI/Swagger is supported: select endpoints visually in the frontend.

## Connection requirements

- API specification URL
- Base URL
- Pagination type
- Authentication type
- Extra headers (optioneel)
