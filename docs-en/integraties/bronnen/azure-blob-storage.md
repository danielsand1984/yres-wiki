# Azure Blob Storage

**Category:** Azure · File

File storage in Azure. Upload files directly and add them as tables.

## Connection requirements

- Account name
- Container name
- SAS token

## Setup

Create a **SAS token** via the storage account → Security + Networking → Shared Access Signature.
