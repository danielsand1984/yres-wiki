# Product overview

## The proposition

**The Azure data platform for reliable dashboards and reporting.** Yres designs, builds and manages your complete data warehouse in Microsoft Azure, so data teams can deliver faster with less maintenance and complexity.

## From source to dashboard — fully automated

The entire chain runs within a single Azure environment:

```
Sources            Design         Orchestration   Storage                Reporting
(Exact, AFAS,  →   (visual    →   (Azure Data  →  (Azure SQL,        →   (Power BI)
 SQL, REST)         pipeline      Factory)         Data Lake)
                    design)
```

1. **Sources** — Exact, AFAS, SQL, REST and more
2. **Design** — design pipelines visually
3. **Orchestration** — Yres translates processes into Azure Data Factory (ADF)
4. **Storage** — Azure SQL, Data Lake
5. **Reporting** — reliable data for Power BI

## The problem Yres solves

Data platforms often grow into complex custom structures that are hard to manage:

- Reports lag behind or are incorrect
- Scripts break and no one knows what happens when things change
- Every new data source takes time and custom work
- Knowledge sits with a single engineer or consultant

With Yres you centralize data sources, pipelines and management within a single Azure environment. This lets you work faster with reliable data, without unnecessary complexity.

## One platform you understand, manage and keep in your own hands

### Your data, your environment
By default, Yres runs entirely within your own Azure tenant. You retain ownership of your data, infrastructure and costs. If you prefer to hand over management, we can also host the environment for you — the choice is yours.

### Less dependent on standalone scripts and specialized knowledge
By standardizing data sources, pipelines and management, the platform stays understandable, transferable and manageable for the whole team.

### Built on proven Azure best practices
Yres uses standardized Azure structures and proven architectures, so data environments remain stable, scalable and manageable.

### Designed to grow with you
With Yres you add data sources without building up extra maintenance overhead or technical debt. This keeps the platform clear and organized as your organization grows.

## Fast onboarding

A complete Yres environment is operational **within an hour** — no lengthy implementation project, no external consultants for the setup. You can typically connect a new source in about **five minutes**.
