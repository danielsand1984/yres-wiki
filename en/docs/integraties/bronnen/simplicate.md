# Simplicate

**Category:** Direct connection

Project and CRM software.

## Connection requirements

- Domain name
- Authentication key
- Authentication secret

## Setup

Create an API key + secret in Simplicate.

## Where to find these

- **Domain name** — this is your own Simplicate environment URL: `https://<org>.simplicate.nl`. `<org>` is your organization's name (shown in the address bar when logged in).
- **Authentication key + Authentication secret** — in Simplicate, go to **Settings → API** and click **New** in the top right to create an API key. You receive an **Authentication-Key** and matching **Authentication-Secret**. An API key is tied to a user and inherits that user's permissions; provide both values to Yres.

Official documentation: [Simplicate — Creating an API key](https://support.simplicate.nl/en/articles/6693108-creating-and-deleting-an-api-key).
