# Tweede Kamer

**Category:** OData

Open data from the Dutch House of Representatives via OData.

## Connection requirements

_No additional connection details needed in this setup._

## Where to find these

The Dutch House of Representatives data is **open data**: no credentials or keys are required. You use the OData feed of the official Open Data Portal.

1. Go to the House of Representatives Open Data Portal ([opendata.tweedekamer.nl](https://opendata.tweedekamer.nl/)).
2. Use the OData API feed URL as the connection URL. You build your own query using entities, attributes and filters in the URL; the API returns data in JSON.

See the official documentation: [OData API — Open Data Portaal](https://opendata.tweedekamer.nl/documentatie/odata-api).
