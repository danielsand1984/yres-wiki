# Integrations

**Yres connects databases, ERP systems, APIs and cloud applications within your own Azure environment. Without custom development, without scripts.**

Add new data sources without extra manual work. Yres standardizes how data is loaded and structured, so your setup stays consistent as it grows.

## Categories

Sources fall under one or more connection types:

| Category | What it is |
| --- | --- |
| **Direct connections** | Native connectors to databases and applications |
| **OData** | Connection via the OData protocol (including SAP, CBS) |
| **REST** | Connection via REST APIs |
| **Custom** | Custom work based on database, OData and REST integrations |

Some sources (Mendix, Monday, Salesforce, Microsoft Graph) connect via multiple protocols and therefore appear under multiple categories.
