# Tweede Kamer

**Categorie:** OData

Open data van de Nederlandse Tweede Kamer via OData.

## Verbindingseisen

_Geen aanvullende verbindingsgegevens nodig in deze opzet._

## Gegevens ophalen

De data van de Tweede Kamer is **open data**: er zijn geen inloggegevens of sleutels nodig. Je gebruikt de OData-feed van het officiële Open Data Portaal.

1. Ga naar het Open Data Portaal van de Tweede Kamer ([opendata.tweedekamer.nl](https://opendata.tweedekamer.nl/)).
2. Gebruik de OData API-feed-URL als verbindings-URL. Via entiteiten, attributen en filters in de URL stel je je eigen query samen; de API levert data in JSON.

Zie de officiële documentatie: [OData API — Open Data Portaal](https://opendata.tweedekamer.nl/documentatie/odata-api).
