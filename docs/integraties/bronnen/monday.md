# Monday

**Categorie:** Directe koppeling · REST

Werk- en projectmanagement. Koppelt via meerdere protocollen.

## Verbindingseisen

- URL
- API token

## Setup

Maak een API-token aan (zie de Monday-documentatie).

## Gegevens ophalen

- **URL** — dit is de URL van je eigen monday-account: `https://<account>.monday.com`. Je ziet deze in de adresbalk wanneer je bent ingelogd; `<account>` is de naam van je organisatie.
- **API token** — log in op monday.com en klik rechtsboven op je avatar (profielfoto) → **Developers** → **My Access Tokens**. Kopieer hier je persoonlijke API v2-token (klik op *Show*). Beheerders kunnen het ook vinden via **Administration → Connections → Personal API token**. Het token erft jouw eigen rechten in monday.

Officiële documentatie: [monday.com API authentication](https://developer.monday.com/api-reference/docs/authentication).
