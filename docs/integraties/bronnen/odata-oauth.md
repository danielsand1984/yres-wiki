# OData OAuth

**Categorie:** OData

OData met OAuth-authenticatie. Grant Type "Authorization Code" vereist een refresh token.

## Verbindingseisen

- URL
- Body URL
- Client ID
- Client secret
- Access token URL
- Scope
- Grant Type
