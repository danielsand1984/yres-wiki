# Azure Blob Storage

**Categorie:** Azure · Bestand

Bestandsopslag in Azure. Upload bestanden direct en voeg ze als tabel toe.

## Verbindingseisen

- Account name
- Container name
- SAS token

## Setup

Maak een **SAS-token** aan via het storage-account → Security + Networking → Shared Access Signature.
