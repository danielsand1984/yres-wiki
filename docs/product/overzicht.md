# Productoverzicht

## De propositie

**Het Azure data platform voor betrouwbare dashboards en reporting.** Yres ontwerpt, bouwt en beheert je complete datawarehouse in Microsoft Azure, zodat data teams sneller kunnen leveren met minder onderhoud en complexiteit.

## Van bron tot dashboard — volledig geautomatiseerd

De volledige keten loopt binnen één Azure omgeving:

```
Bronnen            Ontwerp        Orkestratie     Opslag                 Rapportage
(Exact, AFAS,  →   (visueel   →   (Azure Data  →  (Azure SQL,        →   (Power BI)
 SQL, REST)         pipeline      Factory)         Data Lake)
                    design)
```

1. **Bronnen** — Exact, AFAS, SQL, REST en meer
2. **Ontwerp** — pipelines visueel ontwerpen
3. **Orkestratie** — Yres vertaalt processen naar Azure Data Factory (ADF)
4. **Opslag** — Azure SQL, Data Lake
5. **Rapportage** — betrouwbare data voor Power BI

## Het probleem dat Yres oplost

Dataplatformen groeien vaak uit tot complexe maatwerkstructuren die lastig te beheren zijn:

- Rapportages lopen achter of kloppen niet
- Scripts breken en niemand weet wat er gebeurt bij wijzigingen
- Elke nieuwe databron kost tijd en maatwerk
- Kennis zit bij één engineer of consultant

Met Yres centraliseer je databronnen, pipelines en beheer binnen één Azure omgeving. Zo werk je sneller met betrouwbare data, zonder onnodige complexiteit.

## Eén platform dat je begrijpt, beheert en in eigen hand houdt

### Jouw data, jouw omgeving
Yres draait standaard volledig binnen je eigen Azure tenant. Je houdt eigenaarschap over je data, infrastructuur en kosten. Wil je het beheer uit handen geven, dan kunnen we de omgeving ook bij ons hosten — de keuze is aan jou.

### Minder afhankelijk van losse scripts en specifieke kennis
Door databronnen, pipelines en beheer te standaardiseren blijft het platform begrijpelijk, overdraagbaar en beheersbaar voor het hele team.

### Gebouwd op bewezen Azure best practices
Yres gebruikt gestandaardiseerde Azure-structuren en bewezen architecturen, zodat data omgevingen stabiel, schaalbaar en beheersbaar blijven.

### Ontwikkeld om mee te groeien
Met Yres voeg je databronnen toe zonder extra beheerlast of technische schuld op te bouwen. Zo blijft het platform overzichtelijk terwijl je organisatie groeit.

## Snelle onboarding

Een complete Yres omgeving is **binnen een uur** operationeel — geen langdurig implementatietraject, geen externe consultants voor de inrichting. Een nieuwe bron sluit je doorgaans aan in zo'n **vijf minuten**.
